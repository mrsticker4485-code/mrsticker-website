# Mr Sticker Auto Repair — Desktop App (Electron)

## ساختار فایل‌ها

```
mrsticker-desktop/
├── package.json        تنظیمات پروژه و ساخت نصب‌کننده
├── main.js             پنجره‌ی اصلی برنامه
├── preload.js          پل امن بین برنامه و صفحه
└── renderer/
    └── index.html      خود سایت (همون فایلی که روی گیت‌هاب دارید)
```

## اجرا روی کامپیوتر خودتون

اول Node.js رو نصب کنید (از nodejs.org)، بعد توی پوشه‌ی پروژه:

```bash
npm install
npm start
```

## ساخت فایل نصبی

برای ویندوز (فایل `.exe`):
```bash
npm run build:win
```

برای مک (فایل `.dmg`):
```bash
npm run build:mac
```

فایل خروجی توی پوشه‌ی `dist/` ساخته می‌شه.

## به‌روزرسانی سایت داخل برنامه

هر وقت `index.html` رو تغییر دادید، کافیه فایل جدید رو جایگزین
`renderer/index.html` کنید و دوباره build بگیرید.

## نکات

- لینک‌های تماس (`tel:`)، پیامک (`sms:`)، ایمیل (`mailto:`) و لینک‌های
  اینترنتی مثل فیسبوک، بیرون از برنامه و توی اپ‌های خود سیستم باز می‌شن.
- برای اضافه کردن آیکون برنامه، یک فایل `icon.ico` (ویندوز) یا
  `icon.icns` (مک) توی پوشه‌ی `build/` بذارید — electron-builder
  خودش پیداش می‌کنه.
